# 知识动效图谱

双击 `index.html` 即可使用。页面可离线运行，无需安装依赖。

- 下拉菜单按顺序提供大语言模型基础、预训练与推理、后训练、RAG、Agent 工具调用和 RSI。可在链接中用 `?topic=主题文件名` 直接打开某一章。
- 点击「播放动效」按卡片编号逐张播放。可以暂停并从当前进度继续，或调整至 0.5×–2×。
- 每章均有六步，点击编号和标题可直接跳转。讲解时保留全部卡片，当前步骤高亮并滚动至可见区域。上一步、下一步逐张切换。页面焦点在控件外时，左右方向键切换卡片，Esc 返回总览。
- 展开卡片的「验证方法」查看测试任务。
- 点击「总览」清除高亮。「打印 / PDF」输出静态版。
- 如需视频，使用系统录屏录制浏览器窗口。先打开页面，再点击「播放动效」。

## 添加主题

1. 复制 `topics/llm-post-training.js`，为文件和 `id` 设置新名称。
2. 修改标题、知识卡和来源。步骤导航和播放顺序均由 `cards` 的排列顺序生成。卡片可用正数 `durationMs` 指定 1× 播放时长，默认 5200 毫秒。卡片可通过可选的 `checks` 字符串数组加入验证方法。
3. 在 `index.html` 中将主题文件注册为 `<script defer src="topics/新文件.js"></script>`，放在 `app.js` 之前。刷新后可从下拉菜单切换主题。

| 组件 | 字段 | 用途 |
| --- | --- | --- |
| `bars` | `rows[].label/before/value` | 0–100 的前后百分比 |
| `tokens` | `tokens[].label/active` | Token 与监督位置 |
| `flow` | `steps[]` | 按顺序展示处理步骤 |
| `branches` | `rows[].condition/action` | 按条件展示对应操作 |
| `pairs` | `rows[].label/value/active` | 偏好对或正反示例 |

每种图形都支持 `label` 和可选的 `caption`。卡片色值可选 `cyan`、`purple`、`amber`、`mint`、`rose` 和 `blue`。

维护技术主题时，在 `sources` 记录官方文档、论文或发布说明。涉及具体框架行为时，标明对应版本或文档分支。实测指标写清数据集和评估条件，教学数值在 `note` 中显式标注。主题通过独立脚本维护，可复用页面、图形组件和播放逻辑。
