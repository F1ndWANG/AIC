# 从大语言模型到 RSI

32 个专题共 192 张卡片。每章围绕六个知识点展开。点击单个知识点可直接定位到对应卡片。

| 模块 | 要理解的问题 |
| --- | --- |
| 模型基础 | 文本怎样变成 Token，Transformer 怎样从可见前缀计算下一位置？ |
| 预训练与部署 | 训练数据、优化器和预算如何影响学习，解码、批处理与缓存怎样影响输出和成本？ |
| 后训练、推理与多模态 | SFT、偏好对齐和可验证奖励分别提供什么信号，如何用搜索与预算约束推理，图像和视频证据怎样进入模型？ |
| RAG 与 Agent | 如何找对并核验证据，如何规划、调用工具、从检查点恢复、多任务汇合与维护记忆？ |
| 自我改进与 RSI | 每一轮该更新 Prompt、记忆、工具策略、验证器还是模型权重，怎样用独立验证和留出评估证明改进能够迁移？ |
