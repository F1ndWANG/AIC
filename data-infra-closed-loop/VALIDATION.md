执行 `python3 -m unittest discover -s tests -v`。

13 项测试通过，覆盖：

- 接入幂等和同 ID 不同内容冲突。
- 无效时间导致事务整体回滚。
- 质检隔离、拒绝未通过样本的标签、隔离重试。
- 模拟 Worker 崩溃后重新打开数据库、过期租约回收、旧 token 提交拦截。
- 标签修订乱序、禁止覆盖同一修订、发布后的标签快照固定。
- 同源跨划分拒绝与发布事务回滚。
- 相同内容跨数据版本划分泄漏拒绝。
- 对象损坏、缺失导致发布阻断。
- 缺少训练类别拒绝训练。
- 候选预算、去重与保留集排除。
- 全闭环真实训练、反馈、血缘追踪、预测幂等及回滚。
- 失败门禁和已过时基线门禁拒绝部署。
- 反馈幂等、反馈冲突与无效可用时间拒绝。

租约测试模拟过期并重新打开连接，不是操作系统级 kill 压力测试；当前未做多进程竞争、负载、跨机器或断电持久性验证。

## 合成数据演示

初始数据：66 条有效样本、1 条隔离样本。新增线上模拟样本：24 条。挖掘并复核：18 条。数据版本与训练运行各 2 个。

固定验证集 24 条。初始准确率为 16/24（66.67%），增量训练后为 24/24（100%）；初始 macro-F1 约 0.556，增量后为 1.0。结果来自刻意设置覆盖缺口的合成数值特征，未用于证明视频模型表现或生产收益。

演示保留独立 test 成员但没有用其选择模型。初始部署门槛显式放宽至 0.6，只为使错误回流场景可运行；更新部署门槛为 0.8，另外检查相对基线的类别和来源退化。实际项目需另行确定门槛。

演示验证更新模型切换、恢复上一部署、重新评估后恢复更新模型，以及旧预测依旧关联旧部署。`business_gain_verified` 保持 false。

完整运行输出见 `examples/demo-report.json`。可重新运行 demo 验证；实体 ID 和时间会变化，合成特征及采样使用固定随机种子。
